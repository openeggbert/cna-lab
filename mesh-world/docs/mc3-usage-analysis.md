# MC3 / MeshCraft Usage Analysis

> Status as of 2026-06-26. Describes what MeshCraft and the MC3 format support,
> what MeshWorld actually uses, and where the biggest gaps are.

---

## The Instance Definition Crisis (biggest bug)

C++ chunk generators (`SmallHouseBlockGenerator`, `ParkGenerator`, `RoadGenerator`, …)
emit MC3 `<instance>` references like:

```cpp
w.instance("tree_0",    "tree_apple",  tx, tz);
w.instance("bench_in_0","bench_park",  bx, bz);
w.instance("shrub_l_0", "shrub_round", sx, sz);
```

None of these definition IDs (`tree_apple`, `bench_park`, `shrub_round`,
`tree_oak`, `tree_lime`, `tree_chestnut`, `tree_birch`, …) are ever written into
the generated MC3 document as `<definition id="…">` blocks.
`SceneRenderer` silently skips unresolved instances.

**Result: every tree, bench, shrub, and lamp in the world is invisible.**

The Lua object generators (`generators/lua/object/tree.lua`,
`bench.lua`, `fountain.lua`, `lamp.lua`, …) exist and produce correct geometry,
but `ChunkPipeline` only invokes `"lua.zone.*"` generators — never object
generators. Their output is never embedded as definitions into chunk documents.

**Fix required:** for every definition name referenced by a C++ generator,
either inline a `<definition>` block into the document (generated by the
corresponding Lua or C++ object generator), or load definitions from a shared
library file via `<include file="…"/>`.

## Minimap / World Map Display

No minimap is implemented. `WorldMap` maintains a 200 × 200 grid of
`ChunkInfo` cells (zone + region type per cell), but there is no 2-D rendering
of it. A natural implementation would be an ImGui overlay in the HUD showing
zone colors per cell with a player position marker.

---

## What the World Actually Looks Like Today

- Flat-colored ground planes.
- Simple rectangular boxes for buildings (no window or door geometry visible —
  those are referenced as instances of undefined definitions).
- Cylinder primitives for fence posts and fountain basins.
- No trees, no benches, no shrubs, no lamps (all invisible instances).
- No directional sun, no ambient fill light beyond the renderer default.
- No skybox — distant view is a solid dark-blue clear color.
- No fog — geometry just disappears at the far-clip distance.
- No textures anywhere — every surface is a flat PBR color from
  `MaterialRegistry`.

Estimated active usage of MC3 / MeshCraft capability: **~10 %**.

---

## Priority Gaps to Close

1. **Instance definitions** — highest impact, fixes invisibility of all
   organic content (trees, furniture, lamp posts).
2. **Lighting** — add at least one directional sun light and an ambient fill to
   every generated chunk document.
3. **Textures** — wire `MaterialRegistry` entries to `baseColorTexture` URIs so
   surfaces have photo-realistic tile textures instead of flat colors.
4. **Environment / fog** — add a sky color and linear fog to push visual depth.
5. **Minimap** — render the `WorldMap` grid as a 2-D ImGui overlay.
6. **Richer primitives** — replace boxy tree canopies with spheres / icospheres;
   use cones for conifers; use CSG difference for door/window openings in walls.
