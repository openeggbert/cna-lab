# 40. Post-slice expansion and optional research

[Back to master plan](../plan.md)


Record valuable future ideas without allowing them to block the first complete game loop.

- [ ] **IS-40-001 P2** — Expand Iron City only after the first vertical slice passes all gates.
- [ ] **IS-40-002 P2** — Add districts one at a time with explicit content and performance budgets.
- [ ] **IS-40-003 P2** — Add countryside only when streaming and vehicle gameplay are mature.
- [ ] **IS-40-004 P2** — Add day/night cycle after static lighting and mission staging are reliable.
- [ ] **IS-40-005 P2** — Add weather after base environment/audio/physics material behavior is complete.
- [ ] **IS-40-006 P2** — Add advanced police roadblocks after basic witness and pursuit behavior works.
- [ ] **IS-40-007 P2** — Add branching campaign paths only after linear mission tooling is productive.
- [ ] **IS-40-008 P2** — Add mod support only after package, sandbox, and compatibility contracts are stable.
- [ ] **IS-40-009 P2** — Add photo mode only after camera/render/UI systems are mature.
- [ ] **IS-40-010 P2** — Add replay systems only after deterministic input/state capture is useful for QA.
- [ ] **IS-40-011 P2** — Add public demo telemetry only with explicit privacy design and consent.
- [ ] **IS-40-012 P3** — Research procedural district generation from road graphs and prefab grammars.
- [ ] **IS-40-013 P3** — Research AI generation of MC3 generators rather than only individual assets.
- [ ] **IS-40-014 P3** — Research learned crowd animation selection only after deterministic fallback exists.
- [ ] **IS-40-015 P3** — Research GPU-driven rendering only after CPU bottlenecks are proven.
- [ ] **IS-40-016 P3** — Research large-world origin strategies if Iron City scale exceeds float precision comfort.
- [ ] **IS-40-017 P3** — Research multiplayer only as a separate project; do not retrofit it into the vertical slice.
- [ ] **IS-40-018 P3** — Research VR only as a separate interaction and performance target.
- [ ] **IS-40-019 P3** — Research web builds only after core desktop asset/runtime assumptions are portable.
- [ ] **IS-40-020 P3** — Research historical low-end backend presentation as an optional showcase.
