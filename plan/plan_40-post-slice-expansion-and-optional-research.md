# 40. Post-slice expansion and optional research

[Back to master plan](../plan.md)


Record valuable future ideas without allowing them to block the first complete game loop.

- [ ] **IG-40-001 P1** — Grow Iron City district-by-district: each new district/chapter (including countryside) is part of the locked ~15-20 mission, multi-district v1 campaign, and ships only after its own vertical-slice gate (playable, tested, performant) passes on top of the first district.
- [ ] **IG-40-002 P2** — Add day/night cycle after static lighting and mission staging are reliable.
- [ ] **IG-40-003 P2** — Add weather after base environment/audio/physics material behavior is complete.
- [ ] **IG-40-004 P2** — Add police roadblocks or other pursuit escalation beyond the locked single-escalation chase, only after the base witness/pursuit loop is proven and only if campaign design calls for it.
- [ ] **IG-40-005 P2** — Add branching campaign paths only after linear mission tooling is productive.
- [ ] **IG-40-006 P2** — Add mod support only after package, sandbox, and compatibility contracts are stable.
- [ ] **IG-40-007 P2** — Add photo mode only after camera/render/UI systems are mature.
- [ ] **IG-40-008 P2** — Add replay systems only after deterministic input/state capture is useful for QA.
- [ ] **IG-40-009 P2** — Add public demo telemetry only with explicit privacy design and consent.
- [ ] **IG-40-010 P3** — Research procedural district generation from road graphs and prefab grammars, only if the hand-authored MC3 pipeline becomes the proven bottleneck for adding districts.
- [ ] **IG-40-011 P3** — Research AI generation of MC3 generators rather than only individual assets.
- [ ] **IG-40-012 P3** — Research learned crowd animation selection only after deterministic fallback exists.
- [ ] **IG-40-013 P3** — Research GPU-driven rendering only after CPU bottlenecks are proven and the baked-lighting/limited-shadow target is no longer sufficient.
- [ ] **IG-40-014 P3** — Research large-world origin strategies if Iron City scale exceeds float precision comfort.
- [ ] **IG-40-015 P3** — Research multiplayer only as a separate project; do not retrofit it into the campaign.
- [ ] **IG-40-016 P3** — Research VR only as a separate interaction and performance target.
- [ ] **IG-40-017 P3** — Research web builds only after core desktop asset/runtime assumptions are portable.
- [ ] **IG-40-018 P3** — Research historical low-end backend presentation as an optional showcase.
- [ ] **IG-40-019 P3** — Research full multi-locale runtime infrastructure (language switching, translation pipeline) beyond the locked single-language-plus-stable-IDs v1 target.
- [ ] **IG-40-020 P3** — Research full input-rebinding matrix (every action, every device, conflict detection) beyond the locked basic-rebinding v1 target.
