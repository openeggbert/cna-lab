# 01. Product identity, scope, and legal separation

[Back to master plan](../plan.md)


Keep the game original, commercially usable, and resistant to uncontrolled scope growth.

- [ ] **IG-01-001 P0** — Write a one-page original creative premise for Iron Gang without references to protected plots.
- [ ] **IG-01-002 P0** — Define Iron City geography, history, industries, districts, and social tensions.
- [ ] **IG-01-003 P0** — Define the protagonist, central conflict, and ending at a high level.
- [ ] **IG-01-004 P0** — Create a do-not-copy list covering names, maps, missions, dialogue, cinematography, logos, music, and UI.
- [ ] **IG-01-005 P0** — Define the target rating and content boundaries.
- [ ] **IG-01-006 P0** — Define whether commercial distribution is a project goal.
- [ ] **IG-01-007 P1** — Run a preliminary title and domain collision search before public branding.
- [ ] **IG-01-008 P1** — Create at least twenty alternative project titles in case Iron Gang is unavailable.
- [ ] **IG-01-009 P1** — Create fictional vehicle-manufacturer naming rules.
- [ ] **IG-01-010 P1** — Create fictional business, street, district, newspaper, and radio naming rules.
- [ ] **IG-01-011 P1** — Define the historical era without copying the chronology of another title.
- [ ] **IG-01-012 P1** — Create an original visual-reference board with source/provenance notes.
- [ ] **IG-01-013 P1** — Define explicit project pillars and anti-pillars.
- [ ] **IG-01-014 P1** — Define the intended campaign length for vertical slice, demo, and full game.
- [ ] **IG-01-015 P1** — Define the target player fantasy and moment-to-moment loop.
- [ ] **IG-01-016 P1** — Define scope cuts that preserve the core fantasy.
- [ ] **IG-01-017 P1** — Create a content-approval checklist for legal and identity review.
- [ ] **IG-01-018 P1** — Define rules for real historical names, brands, buildings, and public figures.
- [ ] **IG-01-019 P1** — Define rules for archival photographs and historical recordings.
- [ ] **IG-01-020 P1** — Define a trademark and credits review gate before release.
- [ ] **IG-01-021 P2** — Create a project logo only after the final title is cleared.
- [ ] **IG-01-022 P2** — Create a style guide for naming source files, assets, missions, and characters.
- [ ] **IG-01-023 P2** — Document how inspirations may be cited without marketing the game as a clone.
- [ ] **IG-01-024 P2** — Define community contribution terms for code and assets.
- [ ] **IG-01-025 P2** — Evaluate whether a contributor license agreement is necessary.
