# Third-party software and asset provenance

This file is the asset and dependency provenance ledger. A new external asset
must not be committed until its file name, author, source URL, exact license,
attribution requirement, and modification status appear here.

## Runtime/build dependencies

| Work | Local revision at baseline | License | How used |
|---|---|---|---|
| [CNA](https://github.com/openeggbert/cna) | `1bb2145d99ed572dd4eb15009c34e2e5f410fcf0` | Microsoft Public License (Ms-PL) | Public game/framework abstraction and linked CMake target |
| [sharp-runtime](https://github.com/openeggbert/sharp-runtime) | `54578590b328aa9612fe38bfddca9fd8ca795144` | MIT | Consumed transitively through CNA |

CNA has its own transitive dependencies and notices. This project does not
vendor them; consult the selected CNA checkout when distributing binaries.

## Game assets

No externally sourced game art, font, music, or sound asset is currently
included. Initial graphics are generated by newly written code. Jump, cog,
damage, crawler defeat, projectile, block, completion and UI sounds are original
22.05 kHz mono PCM synthesized at runtime by `ProceduralAudio.cpp`; they contain
no sampled or transcribed historical material and are covered by this project's
MIT license.

## Historical reference (not distributed)

Mike Wiering's `MARIOSRC.ZIP` is downloaded locally from the official source
page into ignored `reference/original/`. It is not a build dependency and is not
part of this repository. Its archive documentation permits study,
experimentation, ports, and limited credited fragment reuse, but restricts
modified redistribution; the contained game is freeware only when unchanged.
See [analysis.md](analysis.md) for the complete finding.

Nintendo-owned characters, trademarks, art, music, sounds, and other material
are neither dependencies nor assets of this project.
