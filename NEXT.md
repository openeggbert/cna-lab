# Black Pine next steps

The current demo is intentionally small but complete. Possible polish work:

1. Replace procedural placeholder art with original sprites/background art while
   keeping the current procedural version as an asset-free test mode.
2. Add sound once Explore2D gains an audio host service.
3. Add more optional examine text and environmental details.
4. Add one small custom puzzle after Explore2D gains a minigame/custom-mode
   interface, to exercise that extension point.
5. Add title/instructions and a dedicated ending screen rather than using only
   the generic host overlays.
6. Add a game/content version to save compatibility once story content changes.
