# Black Pine next steps

The current demo is intentionally small but complete. Possible polish work:

1. Add palette-indexed procedural animation to the beacon, generator and radio
   when Explore2D exposes animation primitives.
2. Add sound once Explore2D gains an audio host service.
3. Add more optional examine text and code-drawn environmental details.
4. Add one small custom puzzle after Explore2D gains a minigame/custom-mode
   interface, to exercise that extension point.
5. Add a game/content version to save compatibility once story content changes.
