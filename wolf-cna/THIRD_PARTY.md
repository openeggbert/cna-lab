# Third-party assets and code

## Current state

The starter contains no third-party game assets.

The wall, floor and ceiling texture atlas is generated at runtime by project-owned C++ code.

CNA and its dependencies are consumed as external build dependencies and retain their own licenses.

## Required record for future assets

For every externally sourced asset add:

- name;
- file path(s);
- author;
- canonical source URL;
- exact license;
- attribution text;
- modification status.

Do not add an asset until its redistribution terms are clear.
