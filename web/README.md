# Explore2D website

This directory contains the dependency-free English presentation and learning
centre for Explore2D. It is ordinary static HTML, CSS and JavaScript:

- `index.html` — engine presentation and API overview;
- `developers.html` — practical developer guide and API patterns;
- `tutorial.html` — a complete 24-lesson course that builds Signal Cabin.

Open `index.html` directly, or serve the directory locally:

```bash
python3 -m http.server 8080 --directory web
```

Then visit `http://localhost:8080/`.

On a Linux desktop, open that URL with `xdg-open http://localhost:8080/`.
The Windows command is `explorer.exe http://localhost:8080/`; plain `explorer`
is not available in this Linux workspace.

Run the dependency-free structural check with:

```bash
python3 web/validate.py
```

The screenshots are generated by the Black Pine renderer and show actual
Explore2D output. No third-party web assets or runtime dependencies are used.

Tutorial completion is stored locally in the visitor's browser. It is never
sent to a server.
