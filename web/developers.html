01 · Mental model

Four layers, one clear boundary.

Explore2D treats a game as immutable definitions plus one mutable session. Rendering is deterministic and CPU-owned. CNA supplies the desktop loop, platform input, final texture and simple audio playback.

WorldDefinitionWhat exists

Rooms, items, rules, art, animations, sounds and presentation.

AdventureSessionWhat changed

Player, inventory, flags, counters, visits, messages and active actions.

AdventureRendererWhat is visible

A fixed 640×350 indexed canvas and the shared Explore2D interface.

AdventureGameHow it runs

The optional CNA host for input, fullscreen, audio and frame presentation.

Recommended workflow

Create and test the world against Explore2D::Core. Add Explore2D::Cna only to the executable that launches the real game.

02 · Project setup

Keep the engine beside the game.

The simplest development layout uses sibling repositories. It keeps the game independent while making local engine changes immediately available.

workspace/
├── explore-2d/
├── cna/                 # required only for the desktop host
└── signal-cabin/
    ├── CMakeLists.txt
    ├── src/
    │   ├── Main.cpp
    │   ├── SignalCabinWorld.cpp
    │   └── SignalCabinWorld.hpp
    └── test/
        └── ScenarioTests.cpp

If Explore2D is not already present, clone it beside the game:

git clone https://github.com/openeggbert/explore-2d.git
git -C explore-2d switch develop

Minimal CMake integration

CMakeLists.txt
cmake_minimum_required(VERSION 3.25)
project(SignalCabin LANGUAGES CXX)

set(CMAKE_CXX_STANDARD 23)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

set(EXPLORE2D_SOURCE_DIR
    "${CMAKE_CURRENT_SOURCE_DIR}/../explore-2d"
    CACHE PATH "Explore2D checkout")

set(EXPLORE2D_BUILD_TESTS OFF CACHE BOOL "" FORCE)
add_subdirectory("${EXPLORE2D_SOURCE_DIR}"
    "${CMAKE_BINARY_DIR}/_deps/explore2d")

add_library(signal_cabin_world src/SignalCabinWorld.cpp)
target_include_directories(signal_cabin_world PUBLIC src)
target_link_libraries(signal_cabin_world PUBLIC Explore2D::Core)

if(TARGET Explore2D::Cna)
    add_executable(signal_cabin src/Main.cpp)
    target_link_libraries(signal_cabin
        PRIVATE signal_cabin_world Explore2D::Cna)
endif()
Headless core
cmake -S . -B build-core \
  -DEXPLORE2D_BUILD_CNA=OFF
cmake --build build-core -j
Desktop CNA host
cmake -S . -B build \
  -DCNA_SOURCE_DIR=/path/to/cna
cmake --build build -j

03 · World definition

Construct the game once.

A game normally exports one function that returns a fully populated WorldDefinition. The session holds a const reference to it, so finish construction before creating a session or host.

SignalCabinWorld.cpp
#include "SignalCabinWorld.hpp"
#include "explore2d/Drawing.hpp"

namespace e2d = explore2d;

e2d::WorldDefinition buildWorld() {
    e2d::WorldDefinition world;
    world.title = "Signal Cabin";
    world.startRoom = "cabin";

    world.addItem({
        "brass_key", "BRASS KEY",
        "A worn key with a triangular bow.", true});

    e2d::RoomDefinition cabin;
    cabin.id = "cabin";
    cabin.label = "SIGNAL CABIN";
    cabin.background = e2d::PaletteColor::blue;
    cabin.defaultSpawn = {32, 232};
    cabin.solids.push_back({0, 260, 492, 28});

    world.addRoom(std::move(cabin));
    return world;
}

Validate before play

auto world = buildWorld();
const auto errors = world.validate();
if (!errors.empty()) {
    throw std::runtime_error(errors.front());
}

e2d::AdventureSession session{world};

validate() catches missing start rooms, invalid or duplicate language IDs, dangling exits, duplicate hotspot or animation IDs, invalid sound steps and broken interaction references. The session constructor also validates and refuses an invalid world.

04 · Drawing system

Draw with EGA primitives.

Game-facing art uses only PaletteColor. This makes arbitrary RGB drift impossible and preserves the exact 16-colour SCREEN 9 identity.

OperationDeclarative visualPurpose
pixelPixelVisualQBasic PSET equivalent
line / rectangleLineVisual / RectVisualLines, boxes and filled areas
circle / ellipse / arcCircleVisual / EllipseVisual / ArcVisualCurved outlines and filled forms
polyline / polygonPolylineVisual / PolygonVisualConnected outlines and filled shapes
paintPaintVisualBoundary flood fill

capture / blitImageVisualIndexed GET/PUT with raster operations

Build reusable motifs with Drawing

void addPine(e2d::RoomDefinition& room,
             e2d::Vec2 origin) {
    e2d::Drawing pine;
    pine.origin(origin)
        .rectangle({-3, -34, 6, 34},
            e2d::PaletteColor::brown)
        .polygon({{-25, -24}, {0, -78}, {25, -24}},
            e2d::PaletteColor::green)
        .polygon({{-19, -48}, {0, -92}, {19, -48}},
            e2d::PaletteColor::brightGreen);
    pine.appendTo(room.decorations);
}
Coordinate rule

Room decoration, solids, hotspots and animation frames all use room-local coordinates. The renderer adds the viewport origin at (8, 8).

05 · Rooms and movement

A room is one authored composition.

The room-local world is 492×262 pixels. Add solid rectangles for floors and platforms, then connect scenes with directional exits and explicit destination spawns.

cabin.solids.push_back({0, 260, 492, 28});
cabin.solids.push_back({210, 205, 90, 12});

cabin.exits.push_back({
    e2d::Direction::right,
    "forest_path",
    {8, 232},
    {},
    {}});

e2d::ExitDefinition lockedExit{
    e2d::Direction::left,
    "radio_room",
    {462, 232},
    {e2d::Condition::flag("door_open")},
    "The radio-room door is locked."};
cabin.exits.push_back(std::move(lockedExit));
  • defaultSpawn is used on new game, map travel and mutations that do not provide another spawn.
  • travelAnchor makes a visited room available on the discovered-location map.
  • turnBeforeWalk makes the first opposite-direction press turn the player without moving.
  • ENTER/Space attempts a nearby contextual rule first and jumps only when none applies.

06 · Hotspots and rules

Separate targets from outcomes.

A hotspot describes where and what something is. An interaction rule describes what a particular intent does to it. Several rules may target the same hotspot under different conditions.

cabin.hotspots.push_back({
    "desk_drawer",
    "DESK DRAWER",
    {174, 190, 126, 70},
    e2d::HotspotKind::mechanism,
    {},
    {e2d::RectVisual{
        {194, 214, 86, 18},
        e2d::PaletteColor::brown, true}}
});

world.addInteraction({
    e2d::Verb::examine,
    "desk_drawer",
    std::nullopt,
    {e2d::Condition::notFlag("key_revealed")},
    {{"Behind the ledger, a brass key catches the light.",
        e2d::MessageStyle::inspect}},
    {e2d::Mutation::setFlag("key_revealed")},
    10,
    "reveal_key_once"
});

When interaction areas overlap, Explore2D prefers the nearby hotspot with an applicable rule for the requested verb. A key lying on a desk therefore wins for TAKE while the desk wins for EXAMINE.

07 · Conditions and mutations

World state is the puzzle language.

Conditions

  • Condition::flag("power_on")
  • Condition::notFlag("gate_open")
  • Condition::has("brass_key")
  • Condition::lacks("fuse")
  • Condition::counterAtLeast("clues", 3)
  • Condition::counterEquals("dial", 7)
  • Condition::visited("tower")

Mutations

  • Mutation::setFlag("power_on")
  • Mutation::clearFlag("alarm")
  • Mutation::addItem("fuse")
  • Mutation::removeItem("fuse")
  • Mutation::addCounter("clues", 1)
  • Mutation::moveTo("tower_top")
  • Mutation::playAnimation("repair")
  • Mutation::win("The signal returns.")

Use priorities for state-specific behaviour

All matching rules are considered; the highest priority wins. Put a specific powered/open/repaired rule above a general fallback. Use onceFlag when the rule itself must execute only once.

Drive F1 help from the same state

Hints are localized, read-only definitions. F1 shows the highest-priority matching hint, and declaration order resolves a tie. A required early objective can therefore stay above later guidance without a separate quest tracker.

world.hints.push_back({
    tr("Examine the desk for the missing key.",
       "Prozkoumej stůl a najdi chybějící klíč."),
    {e2d::Condition::flag("met_caretaker"),
     e2d::Condition::notFlag("key_found")},
    50});

const e2d::HintDefinition* hint = session.currentHint();

08 · Dialogue

Anchor every line to its speaker.

Messages appear as compact blue bubbles and keep the room visible. Speech can follow the target character or the player independently on every line.

world.addInteraction({
    e2d::Verb::context, "caretaker", std::nullopt, {},
    {
        {"Mara: The transmitter lost power at dawn.",
            e2d::MessageStyle::speech,
            e2d::MessageSpeaker::target},
        {"I will inspect the generator.",
            e2d::MessageStyle::speech,
            e2d::MessageSpeaker::player},
        {"Mara: Take the path beyond the gate.",
            e2d::MessageStyle::speech,
            e2d::MessageSpeaker::target}
    },
    {e2d::Mutation::setFlag("met_mara")},
    10, "first_talk"
});
inspect

Observation or action result, normally anchored to the player.

speech

Character dialogue; automatic mode follows the interaction target.

system

Save/load feedback and engine-level information.

warning

Blocked actions, danger and failure cues.

09 · Selective animation

Animate an overlay, not the entire world.

Every frame is a list of ordinary procedural visuals. Durations use QBasic's 18.2 Hz timer ticks. Autoplay animations are ideal for indicators; rule-triggered animations are ideal for actions.

Conditioned looping animation

room.animations.push_back({
    "beacon",
    true,   // autoplay
    true,   // loop
    {e2d::Condition::flag("power_on")},
    {
        {8, {e2d::CircleVisual{
            {230, 40}, 7,
            e2d::PaletteColor::brightRed, true}}},
        {8, {e2d::CircleVisual{
            {230, 40}, 4,
            e2d::PaletteColor::red, true}}}
    }
});

One-shot action animation

room.animations.push_back({
    "repair_spark", false, false, {}, {
        {2, {sparkLeft}},
        {2, {sparkRing}},
        {3, {sparkRight}}
    }});

// Add this to the successful repair rule:
e2d::Mutation::playAnimation("repair_spark")
Keep it selective

A static tree does not need an animation object. Use animation when motion communicates state, consequence or character action.

10 · QBasic-style audio

Compose effects from tones and ticks.

Explore2D intentionally exposes a historical sound vocabulary: frequency in hertz, duration in 18.2 Hz timer ticks, frequency zero for a rest, and one monophonic voice.

world.addSoundEffect({
    "pickup",
    {
        {440, 1},
        {660, 1},
        {880, 2}
    },
    0.15F
});

world.presentation.sounds.pickup = "pickup";
world.presentation.sounds.warning = "warning";

// A rule may override the general binding:
rule.soundEffect = "unlock";

Core code validates and queues effect IDs without touching an audio device. The CNA adapter synthesizes signed 16-bit mono square-wave PCM and plays it through CNA SoundEffect. A new effect interrupts the previous one.

11 · Runtime localization

Translate values, not game state.

Every player-facing value accepts LocalizedText. Its fallback is normally English, while translations use stable language IDs. Plain string literals still work for a single-language game.

e2d::LocalizedText tr(std::string english,
                      std::string czech) {
    e2d::LocalizedText text{std::move(english)};
    text.addTranslation("cs", std::move(czech));
    return text;
}

world.localization.defaultLanguage = "en";
world.localization.languages = {
    {"en", tr("English", "Angličtina")},
    {"cs", tr("Czech", "Čeština")},
};

world.title = tr("Signal Cabin", "Signální stanice");
world.addItem({"key", tr("KEY", "KLÍČ"),
    tr("A small brass key.", "Malý mosazný klíč."), true});

Use the same helper for room and hotspot labels, code-drawn text, dialogue, item descriptions, blocked exits, hazards, terminal messages and world.interfaceText. The bitmap font decodes UTF-8 and includes Czech accented capitals.

Settings are engine-owned

The title menu includes Settings. Escape during play opens a pause menu with the same language selector. A change redraws the current screen immediately and the CNA host stores the preference separately from save-game state.

12 · CNA host

Turn the tested world into a desktop game.

Main.cpp
#include "SignalCabinWorld.hpp"
#include "explore2d/CnaGame.hpp"

int main() {
    explore2d::cna::HostConfig host;
    host.windowTitle = "Signal Cabin";
    host.presentationScale = 2;
    host.savePath = "signal-cabin.e2dsave";
    host.settingsPath = "signal-cabin.e2dsettings";
    host.audioEnabled = true;

    explore2d::SessionConfig session;
    session.turnBeforeWalk = true;

    explore2d::cna::AdventureGame game{
        buildWorld(), session, {}, host};
    game.Run();
}

The host maps the standard controls, uploads one CPU-rendered RGBA texture with point sampling, letterboxes at integer scale, opens context help with F1, toggles fullscreen with F11 and drains monophonic sound cues. Help freezes the current session presentation and closes with F1, Enter or Escape.

13 · Saving and deterministic tests

Test the route, not only the functions.

SessionSnapshot stores the stable adventure state: current room, player, selected verb, inventory, flags, counters, visited rooms and travel anchors. Transient bubbles, poses, sounds and action animations are deliberately not saved.

auto world = buildWorld();
e2d::AdventureSession session{world};

// Place the player beside a pickup in a test helper.
auto snapshot = session.snapshot();
snapshot.roomId = "cabin";
snapshot.player.position = {205, 232};
snapshot.player.grounded = true;
assert(session.restore(snapshot));

session.performVerb(e2d::Verb::take);
assert(session.hasItem("brass_key"));
assert(session.player().pose == e2d::PlayerPose::taking);

while (session.mode() == e2d::SessionMode::message) {
    session.advanceMessage();
}

Recommended test layers

  1. 1
    World validation

    No dangling IDs, exits, sound bindings or animation cues.

  2. 2
    Full winning route

    Script every required collection, reveal, use, transition and final action.

  3. 3
    Failure route

    Exercise hazards, blocked conditions, death and restart independently.

  4. 4
    Renderer preview

    Write indexed frames for title, rooms, dialogue and transient actions.

  5. 5
    CNA smoke test

    Start the actual host for a bounded number of frames with dummy video/audio.
