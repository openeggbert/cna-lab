C++ Chunk Generators

20 Built-in Zone Generators

Each C++ generator produces a complete 64×64 m chunk as an MC3 XML scene. They serve as production-ready defaults and as fallbacks when no Lua override exists.

Lua Map

Planet (Lua)

Level-0 planet generator: whole-planet elevation/moisture fields via noise::fbm, biome classification, culture assignment. Runs live in MapPipeline at the root of the quadtree.

lua.map.planet.default
Lua Map

Continent (Lua)

Level-3 child generator descending from the planet tile. Derives elevation/moisture from its parent's edges (constraint propagation) and emits MountainRange features.

lua.map.child.level3.default
Lua Map

Region (Lua)

Level-7 child generator. Emits Town features via an explicitly-labelled v1 stub (random site sampling) — not yet using the real Settlements::place() suitability model.

lua.map.child.level7.default
